# Kotlin Basics & Null Safety Learning

This repository contains my practice programs and notes while learning the foundational concepts of the **Kotlin** programming language.

## 🚀 Key Concepts Covered

* **Functions:** Defining and calling functions with zero, one, or multiple inputs.
* **Variables:** Understanding the difference between mutable (`var`) and read-only (`val`) variables, as well as data types like `String`, `Int`, and `Boolean`.
* **Nullability & Null Safety:** Learning how to prevent app crashes (`NullPointerException`) using:
  * Safe Call Operator (`?.`)
  * Not-Null Assertion Operator (`!!`)
  * `if/else` Conditionals with Smart Casting
  * Elvis Operator (`?:`) to provide fallback default values.

## 🛠️ Tech Stack
* **Language:** Kotlin
* **Environment:** Kotlin Playground / IntelliJ IDEA

## 📝 Practice Exercises Included
* Full name printing function with parameter configurations.
* Input handling from the user using `readln()`.
* Safe calculations and data transformations with nullable values.
